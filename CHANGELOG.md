# Changelog

## 1.1.0 — 2026-11-07

- Integrated LOW, MEDIUM, and HIGH intensity profiles directly into the skill.
- Replaced long intensity prompts with a skill invocation and a single `Motion intensity:` line.
- Set the Codex default prompt to the built-in MEDIUM profile.

- Added dedicated installation and invocation instructions for Claude Code, Google Antigravity, Cursor, and GitHub Copilot.
- Added a Compatible Agents section and links to official discovery documentation.

## 1.0.0 — 2026-11-07

Initial public release.

- English `web-motion-ultra` skill and Codex UI metadata.
- Concept, signature moment, motion mapping, implementation, and verification workflow.
- Effect-selection, implementation/QA, and smooth responsive-motion references.
- Desktop/touch profiles, interruptible transitions, reduced motion, and performance diagnosis.
- Installation guide, prompt cookbook, contribution guidance, and package validation.

This release provides instructions and documentation. No cross-device browser benchmark or completed site demo is included.
